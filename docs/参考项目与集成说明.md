## 发布包中的第三方组件

GitHub Release 的桌面分发包包含 Node.js `22.19.0`、REA `6.5.0` 及运行依赖，以便启用 REA MCP 时不必通过 `npx` 首次下载。相关上游许可证和声明随组件文件保留在发布包中。REA 默认关闭，并仅对逆向分析 Agent 可见。

内置运行时只解决 MCP 服务本身的启动环境，不等于把所有逆向分析器打包进 ARTEX。REA 所调用的分析器、设备工具、驱动或平台 SDK 仍可能需要用户按上游文档单独安装、配置并接受其各自许可。

发行包不应包含用户的 `config.json`、`jwt.key`、`data/`、数据库、API Key 或其他本地运行数据。技能文件中的第三方内容与组件许可证也应一并保留。

## 当前版本变更

### v0.3.18 · 2026-10-21

- Windows 首次启动会把 PostgreSQL 初始化原始错误写入 `data/initdb.log`；Release 回归会保留该日志，便于定位干净 Runner 上的初始化问题。
- Release 打包前检查 PostgreSQL 运行时 DLL 是否齐全，缺失时及时中止。

### v0.3.17 · 2026-10-21

- 对话分支、逆向拖放文件与粘贴图片；继续保持安全测试与逆向模式隔离。
- 统一 Windows 双击入口，自动避开占用端口，实例复用，后台守护与启动日志诊断。
- Windows 发布前运行真实 PostgreSQL 启动回归，验证中文路径、并发双击、端口冲突与重启流程。
- 启动器改动需要下载完整包升级；保留个人数据、配置与密钥，不把它们放入分发包。

### v0.3.16 · 2026-10-18

- 为逆向分析模式内置 REA MCP 运行时：发布工作流按目标平台提供 Node.js、REA 及 npm 运行依赖；ARTEX 优先使用包内运行时，源码环境仍保留 `npx` 回退。
- 逆向分析模式支持选择文件夹并保留相对目录结构；文件夹导入只允许用于逆向会话，普通安全测试模式仍按普通文件上传处理。
- 保持安全测试与逆向分析的 Agent、对话及上下文隔离；REA MCP 默认关闭，启用后只向逆向 Agent 暴露。
- 更新中文界面、仓库更新源与逆向分析说明，并保留适用范围和免责声明。
- 发行工作流生成 Linux、macOS、Windows 多平台压缩包及 SHA-256 校验文件。
